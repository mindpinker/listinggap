# Name and trademark preliminary check

Date: 2026-11-12
Name in use: **ListingGap**
Status: preliminary screen only. **Not legal advice.** A trademark attorney must run the
full register search before paid promotion, a company name, or a domain purchase.

## 1. Chrome Web Store

Searched the public Chrome Web Store from a US-proxied Chrome session on 2026-11-12.

| Query | Result |
| --- | --- |
| `ListingGap` | No results at all (CWS returned “no search results”). |
| `Listing Gap` | ListingLens, Listvana, Citation Gap Finder. No ListingGap. |
| `Listing Doctor` | Two extensions use the name: “Listing Doctor — Why No Sales? for Etsy” and “Listing Doctor — 跨境电商 Listing 诊断工具”. |

Conclusion: no exact CWS collision for `ListingGap` today. `Listing Doctor` is already
taken and must not be used.

## 2. Direct competitor found during the check

**ListingLens** — “Extract Amazon listing and review data free. Unlock Pro AI for title,
bullet, image-text, and ad-angle fixes.”

- Same buyer, same job, same free-data / paid-fix split.
- This is the closest competitor seen so far and should be tracked weekly.
- Differentiation for ListingGap: no account, no upload, no Pro upsell, and an explicit
  proof-gap / claim-safety layer rather than a generic AI rewrite.

## 3. Official trademark registers

| Register | Result on 2026-11-12 |
| --- | --- |
| USPTO Trademark Search (tmsearch.uspto.gov) | Not completed. The public search is JS- and captcha-gated; direct API probes returned 404. |
| EUIPO eSearch plus | Not completed. Interactive search only. |
| WIPO Global Brand Database | Not completed. The endpoint returned an Altcha challenge page. |

Do **not** treat the absence of a web-search hit as a clearance. “ListingGap” is a
descriptive compound (listing + gap), which makes it harder to protect and easier for
another seller to use a similar name.

## 4. Practical decision

- Keep `ListingGap` for the free launch: the CWS name is available and the exact string
  does not appear in the store.
- Do not spend on paid ads, a trademark filing, or branded merchandise until an attorney
  completes USPTO + EUIPO + WIPO clearance.
- Before any rename, check these candidates in CWS and the registers:
  `ListingGap`, `GapProof`, `ObjectionMap`, `ProofGap`, `ListingProof`.
- Keep the store listing title descriptive (“ListingGap — Amazon Listing Audit & Rewrite”)
  so the product remains findable if the brand later changes.

## 5. What was actually verified

- CWS search pages rendered and were read directly (not inferred from a web search).
- Two `Listing Doctor` items were observed in the live results.
- ListingLens was observed in the live results with its current description.
- Official register searches were **not** completed; that gap must be closed before any
  paid acquisition.
